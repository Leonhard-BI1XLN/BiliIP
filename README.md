# BiliIP+

这是一个可直接加载到 Microsoft Edge 的 Manifest V3 扩展，用于增强 B 站网页版：

- 显示 B 站公开提供的评论“IP 属地”；“回复我的”消息列表也会在回复正文下方显示同一条评论的公开属地。
- 评论信息改为无底色文字，例如 `IP: 江苏`；会替换 B 站默认时间：当天显示每秒更新的相对时间，昨天显示“昨天 + 时间”，更早评论则按设置中的格式显示。时间格式可选 `dd/mm/yyyy hh.mm.ss`、`yyyy/mm/dd hh:mm:ss` 或 `mm/dd/yyyy hh:mm:ss`，默认保持第一种。
- 公共属地名称使用本机的完整国家/地区映射（覆盖如 `斯里兰卡 → Sri Lanka`），不查询第三方定位服务。
- 提供本地固定词典的英文界面模式；设置页语言、应用到 B 站网页的语言、评论翻译目标语言可分别选择。词典覆盖首页、动态菜单、悬浮提示、消息中心和说明文本，并持续处理页面懒加载的固定 UI。
- 评论正文和视频标题默认完全不翻译；点击评论或消息回复旁的 Google Translate 图标后，优先使用 Edge 的本机 Translator API 原位转换到设置的目标语言。视频标题翻译已关闭。
- 用用户自己的静态图片替换 B 站首页顶部横幅，遮住会跟随鼠标产生景深的动态视觉层，并隐藏横幅左侧冗余的 Bilibili 跳转图标。
- 在 B 站视频页隐藏右侧 `video-card-ad-small` 广告卡片；不移除 B 站的 Vue 节点，避免影响评论、作者卡片和操作区，也不请求广告拦截服务。
- 提供完整设置页，使用下方裁切预览中的“＋”作为唯一上传入口；图片可在同一画布内平移、缩放和裁切。

## 能力边界

B 站网页数据不公开评论者的真实 IP。公开“IP 属地”通常只到省、自治区、直辖市或国家/地区，有时完全不返回。因此扩展无法可靠地显示地级市或区县，也不会伪造更精确的位置。旧评论或未登录状态下缺少属地时，设置中可选择隐藏或显示“IP: 未提供”。

英文模式不调用在线翻译服务：它只翻译本地词典收录的固定界面文字、公开属地名称和本扩展添加的字段，并直接替换页面的原文字段。为避免改变用户创作内容，视频标题、评论正文、私信和弹幕不会被自动翻译；消息中心回复者用户名也不会被翻译。视频标题只通过标题旁的手动按钮翻译。

Google Translate 图标是手动功能：点击某条评论或消息中心回复后才会调用 Edge 的本机 Translator API。支持与否取决于 Edge 版本及语言对；第一次使用某语言对时，浏览器可能下载本地模型。成功后译文会原位替换正文；再次点击图标可恢复原文。扩展不提供云端翻译回退，不会把评论正文、IP 属地或设置上传给扩展服务。图标是随扩展打包的 Google Material SVG，不会在运行时从网络加载。

消息中心的原始“回复我的”列表只含评论标识、回复时间和正文，不含 IP 属地。进入该页面时，扩展仅向 B 站官方回复列表读取当前可见批次，并以列表已给出的 `subject_id / root_id / source_id / business_id` 查询 B 站官方评论详情接口；结果只留在当前页面内存。若 B 站未返回属地、评论已删除或该业务类型不支持查询，则会遵循“缺少属地时隐藏/显示 IP: 未提供”的设置，不会猜测位置。

属地英文名遵循 Unicode CLDR/浏览器 `Intl` 的标准本地名称，例如 `Hong Kong SAR China`、`Macao SAR China`、`Taiwan`。不会内置隐藏的 A/B 地域命名开关；如需不同的公开标注政策，应制作清楚标明差异的独立版本，而不应在用户不知情时切换。

## 安装到 Edge

1. 如果拿到的是 ZIP，先解压到一个长期保留的文件夹；不要直接从压缩包加载。
2. 在 Edge 地址栏打开 `edge://extensions`。
3. 打开页面左侧或右侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择本项目根目录，也就是包含 `manifest.json` 的 `Bili插件` 文件夹。
6. 安装后会自动打开设置页。保存需要的选项与横幅图片。
7. 打开或刷新 `https://www.bilibili.com/` 或 `https://message.bilibili.com/`。已打开的 B 站页面必须刷新一次，内容脚本才会生效。

点击浏览器工具栏里的扩展图标即可再次打开完整设置页。若图标没有显示，可先在 Edge 的“扩展”菜单中固定它。

## 使用提示

- 评论信息会随评论区加载、翻页、排序和展开楼中楼自动补充，并且从评论正文下方挂载，使主评论和楼中楼都与正文左侧对齐。“回复我的”页面也会将属地、时间和图标翻译按钮挂在回复正文下方。
- “北京时间”会固定按 `Asia/Shanghai` 格式化；“浏览器本地时间”会跟随电脑时区。时间格式下拉选项会同时应用到评论、消息回复和设置页预览。
- “界面语言”只影响扩展设置页；“B 站页面语言”只影响 B 站网页上的本地英文词典；“评论翻译目标语言”只影响你手动点按评论、消息回复或标题图标后的输出，三项互不联动。
- 自定义横幅只在 B 站首页 `/` 生效。关闭横幅功能或删除图片后，原站横幅会恢复。
- 视频页右侧广告卡片由扩展在本地 DOM 中移除；离开视频页后不执行这段清理。
- 图片裁切结果保存在本机 Edge 的扩展存储中，不会上传。

## 更新与卸载

- 更新本地文件后，在 `edge://extensions` 找到本扩展并点击“重新加载”，随后刷新 B 站页面。
- 卸载扩展会由 Edge 删除它的本地设置和裁切图片；原 B 站页面不会被永久修改。
