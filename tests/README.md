# 本地测试

运行：

```powershell
node tests/run-tests.mjs
```

测试仅使用 Node.js 内置模块，不需要 `npm install`。每项检查独立执行，一项失败不会阻止后续检查，因此一次运行可以看到完整的问题列表。

覆盖范围：

1. `manifest.json` 是 Manifest V3，权限和 B 站匹配范围最小化，并且引用的扩展资源全部存在。
2. 所有 `.js` / `.mjs` / `.cjs` 文件都通过 `node --check` 语法检查。
3. 扩展页 CSP 禁止远程脚本、`unsafe-eval` 和内联脚本；HTML 仅引用随扩展打包的资源。
4. 自定义设置页包含评论开关、IP 属地、秒级时间、时区、按需评论翻译目标语言、图片上传、裁切、预览、缩放、画质、保存、删除和恢复默认值控件，以及彼此独立的设置页语言、B 站页面语言和评论翻译目标选项。
5. 实际时间格式化函数验证默认英国格式 `dd/mm/yyyy hh.mm.ss`，以及 `yyyy/mm/dd hh:mm:ss`、`mm/dd/yyyy hh:mm:ss` 两种可选格式，使用 24 小时制并验证上海时区和闰日边界。
6. 评论元数据验证当天的逐秒相对时间、“昨天 + 时间”、较早日期的精确英国格式、`IP: xx` 文本格式、正文左对齐挂载、默认时间隐藏和无底色样式。
7. 本地英语词典、完整国家/地区映射、动态悬浮菜单属性翻译、三个独立语言偏好和 Edge 本机手动翻译入口均有检查，且不会静默连接在线翻译服务。
8. 实际评论提取函数处理顶层评论、楼中楼、字符串形式的 64 位 `rpid`、秒级 `ctime`，以及 B 站未提供 IP 属地的情况。
9. 横幅实现提供多个 B 站 DOM 选择器回退，只在首页生效，且不会重新引入鼠标跟随效果。

评论样例在 `fixtures/replies.json`。它只包含人工构造的最小数据，不包含真实用户信息。
